# Проверка AI Astana Atlas / VELTARQ

Дата: 23 сентября 2026.

## Реализованный контракт

Расчётный движок и поиск соседних допустимых сценариев переиспользованы без изменения формул. LLM получает полные рассчитанные результаты, районные дельты, вклады мер и синергий, бюджет и каталог проверенных фактов. Для сравнения передаются оба серверных результата. Ответ модели содержит только ID фактов; неизвестные, повторные, ошибочно отнесённые к разделу и пропущенные обязательные ссылки отклоняются. Числа и отображаемые утверждения формирует сервер.

Результат `/simulate` доступен до ответа `/analyze`. При отказе, таймауте, отсутствии настройки или некорректном ответе отображается «Автоматическое объяснение без ИИ». Ошибка объяснения не удаляет расчёт. Запросы отменяются и поздние ответы игнорируются при изменении плана, в том числе при возвращении к прежнему набору. Применение альтернативы обновляет редактор и автоматически повторяет проверку, расчёт и объяснение.

Предпросмотр каталога также выполняет backend через тот же движок. У неполного плана не отображается итоговый Score. Карта, шрифт, цвета, CSS и расположение основных панелей сохранены.

## Проверка браузером с настоящим backend

Backend перезапущен с новым контрактом на `127.0.0.1:8000`; сайт проверен в Chrome на `127.0.0.1:5175`. Перечисленный ниже браузерный прогон выполнен до добавления ключа; последующая проверка живой LLM указана отдельно.

1. Пять мер примера: M7, M8, M10 в Нуре; M12 для города; M5 в Сарыарке. Получен Score **56.54307** и объяснение с честной пометкой fallback.
2. Серверный поиск предложил заменить M5 на M3 в Нуре: Score **57.20556**, улучшение **0.66249**, бюджет **100**.
3. Сравнение показало выигрыш Нуры и компромисс Сарыарки: E2 **48.75 → 40**, C1 **47.5 → 45**.
4. Применение обновило редактор, убрало прежнее объяснение и автоматически подтвердило Score **57.20556** новым расчётом.
5. Удаление меры немедленно убрало итоговый результат. Через каталог проверен серверный предпросмотр M5 в Сарыарке: E2 **40 → 48.75**, C1 **45 → 47.5**. Исходный пример восстановлен; повторный расчёт дал **56.54307**.

## Реальный провайдер LLM

**Реальные запросы к GPT-6 Luna выполнены успешно.** После добавления пользователем ключа `npm run test:llm` подтвердил отдельно объяснение примера и сравнение с рассчитанной альтернативой: оба результата имеют `provider=llm`, корректную структуру и проверенные ссылки на факты. Итог команды — `LIVE LLM VERIFIED: explanation and comparison both succeeded`, код выхода 0.

Backend перезапущен с серверным `backend/.env`. Дополнительный реальный запрос через HTTP-прокси сайта `http://127.0.0.1:5175/api/v1/scenarios/analyze` вернул HTTP 200, `provider=llm`, `fallback_reason=null`, 12 проверенных фактов и неизменные Score **52.55768 → 56.54307**. Это подтверждает работу цепочки сайт → backend → OpenAI, а не только отдельного тестового скрипта.

Повторная живая проверка: `npm run test:llm`. Команда выполняет объяснение и сравнение; fallback не засчитывается как успешная LLM-интеграция. Ключ хранится только в серверном `.env`, не выводится в консоль и не отправляется браузеру; `.env` исключён из Git и Docker build context.

## Подключение GPT-6 Luna

По запросу пользователя выбрана `gpt-6-luna`. Серверный `backend/.env` настроен: `VELTARQ_LLM_BASE_URL=https://api.openai.com/v1`, `VELTARQ_LLM_API_MODE=responses`, `VELTARQ_LLM_MODEL=gpt-6-luna`. Введённый пользователем ключ перенесён из ошибочно заполненного поля API_MODE в `VELTARQ_LLM_API_KEY`; значение ключа не выводилось и не публиковалось.

Адаптер поддерживает Responses API для Luna и Astra: строгая JSON Schema, `store:false`, ограничение выхода, проверка завершённости/отказа и прежняя проверка ссылок на факты. Chat Completions сохранён для совместимости. Регрессионная проверка после изменения: **126 backend-тестов passed, покрытие 98,88%, Ruff passed**. Из них **80 тестов LLM-адаптера**; запросы провайдера замоканы.

**Доступ к GPT-6 Luna подтверждён живыми запросами**, включая вызов через API работающего сайта. Проверки ошибок и отмены запросов остаются автоматическими тестами с моками, как указано выше.
