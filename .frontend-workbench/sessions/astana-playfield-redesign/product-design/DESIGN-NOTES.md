# Новый вариант карты Астаны

Предыдущий вариант сохранял шаблонную конструкцию: длинная левая колонка, одинаковые рамочные блоки, карта как приложение к панели. Декоративные SYS/GRID-коды и мелкий разреженный текст добавляли шума, но не помогали выбрать район или сравнить результат. Перекраска этой структуры не меняла впечатление.

Новый вариант строится вокруг самой географии. Пять районов объединены нижней полосой; силуэты получены из их сохранённых GeoJSON. Выбранный район раскрывается в одном паспорте, а переключатель сценария расположен рядом с индексом города. На узком экране паспорт сворачивается, все районы доступны в горизонтальной навигации.

Типографика: Onest, локальный файл с OFL. Проверены все русские буквы, специфические казахские Ә Ғ Қ Ң Ө Ұ Ү Һ І в обоих регистрах и базовая латиница. Голос этого шрифта подходит компактному городскому инструменту: отчётливые цифры, спокойные подписи, выразительный заголовок без моноширинной стилизации. Golos Text даёт более редакционный характер; IBM Plex Sans — более технический. Эти две альтернативы также проверены по cmap, но в данном варианте используется одна гарнитура для цельности.

Прототип: `product-design/preview/`, сохранённый runnable-архив: `artifacts/after-selected-desktop.zip` относительно сессии. Данные импортируются из существующих файлов проекта; географическая подложка остаётся OpenFreeMap.

Состояние: показ для оценки. Перенос выбранного направления в React через frontend-project-fit следует после пользовательского выбора согласно исходному запросу.
