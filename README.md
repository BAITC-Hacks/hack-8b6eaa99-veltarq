# VELTARQ

## Участник проекта

Я — QA-инженер проекта **VELTARQ**. Отвечаю за контроль качества продукта, поиск и документирование дефектов, а также за сопровождение исправлений в клиентской и серверной частях системы.

## Моя зона ответственности

- Функциональное и регрессионное тестирование новых возможностей.
- Проверка пользовательских сценариев, интерфейсов и API.
- Выявление, описание и приоритизация дефектов.
- Воспроизведение проблем и контроль их исправления.
- Исправление ошибок во frontend-части проекта.
- Исправление ошибок во backend-части проекта.
- Проверка интеграции между клиентской и серверной частями.
- Поддержание актуальной тестовой документации.

## Подход к качеству

Работа строится на раннем выявлении рисков, прозрачном описании проблем и обязательной проверке исправлений. Каждое изменение должно быть протестировано в рамках затронутого пользовательского сценария и не нарушать ранее реализованный функционал.

## Взаимодействие с командой

Я взаимодействую с разработчиками и участниками команды на всех этапах работы: от уточнения требований до финальной проверки результата. Для каждого найденного дефекта фиксируются условия воспроизведения, фактический и ожидаемый результаты, а также приоритет исправления.

## Цель

Обеспечить стабильную, предсказуемую и удобную работу сервиса для пользователей.
