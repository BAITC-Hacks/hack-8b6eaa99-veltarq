# Backend-разработка VELTARQ

Я являюсь backend-разработчиком проекта **VELTARQ** — AI-симулятора управления городом «Аким на 5 часов». Отвечаю за сервисную часть приложения: архитектуру API, бизнес-логику, обработку данных и взаимодействие с фронтендом.

## Зона ответственности

- Разработка и сопровождение API на Python и FastAPI.
- Подготовка и проверка исходных данных по районам города.
- Реализация расчётов, бюджетных ограничений и правил применения мероприятий.
- Расчёт показателей районов и итоговой оценки сценария.
- Сравнение сценариев и подбор допустимых улучшений.
- Сохранение результатов в SQLite и формирование рейтинга команд.
- Интеграция AI-аналитики с результатами серверных расчётов.
- Автоматическое тестирование серверной логики и взаимодействия компонентов.

## Принципы реализации

Числовые результаты рассчитываются сервером по правилам датасета. AI-компонент объясняет полученные результаты и не является источником исходных числовых данных. Передача данных в контекст модели не означает её обучение на датасете.

Приоритеты разработки — воспроизводимость расчётов, проверка входных данных, согласованность API с фронтендом и понятная техническая документация.

## Взаимодействие с командой

Согласовываю контракты API с frontend-разработчиком, обеспечиваю корректную передачу данных между компонентами и участвую в проверке пользовательских сценариев совместно с QA-инженером.
